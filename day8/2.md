TCS An Equilibrium Index of an array is an index such that the sum of elements at lower indices is equal to the sum of elements at higher indices.

TCS NQT often tests this problem because it filters out candidates who use a brute-force O(N²) approach instead of the optimized linear approach.

The Optimal Logic

Calculate Total Sum: 

Find the sum of the entire array first.
Track Left Sum: 

Start iterating from left to right, maintaining a running leftSum.

Calculate Right Sum: 
At any index i, the rightSum is simply totalSum - leftSum - arr[i].

Compare: 
If leftSum == rightSum, you found an equilibrium index.

Optimized Java Solution (O(N) Time, O(1) Space)

import java.util.Scanner;

public class Main {
    public static int findEquilibrium(int[] arr) {
        long totalSum = 0;
        long leftSum = 0;

        // Step 1: Calculate total sum of the array
        for (int num : arr) {
            totalSum += num;
        }

        // Step 2: Iterate and check for equilibrium condition
        for (int i = 0; i < arr.length; i++) {
            // Right sum is total sum minus left sum minus current element
            long rightSum = totalSum - leftSum - arr[i];

            if (leftSum == rightSum) {
                return i; // Found the equilibrium index (0-indexed)
            }

            leftSum += arr[i]; // Update left sum for next iteration
        }

        return -1; // Return -1 if no equilibrium index exists
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        if (!sc.hasNextInt()) return;
        int n = sc.nextInt();
        
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        sc.close();

        System.out.println(findEquilibrium(arr));
    }
}
